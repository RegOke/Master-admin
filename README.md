# Advoc8 master admin prototype

[Open the prototype](https://regoke.github.io/Master-admin/)

Standalone baseline of Anthony Albanese's master person edit page, based on the Advoc8 staging page captured on 10 November 2026. The editable form, original content and right-hand cards are preserved. Dropdowns, name rows, addresses and save actions operate locally; changes reset on refresh.

This does not connect to Advoc8. Navigation outside the master person edit page is not reproduced. Supporting secondary dialogs are demonstration placeholders where a separate screen has not been inspected.

The published `index.html` is self-contained. Unzip `source.zip` for editable HTML, CSS, JavaScript and assets. Run it with `python3 -m http.server 6274` and open `http://127.0.0.1:6274/`.
